Инструкция

Как добавить аккаунт Selectel, настроить зоны, Telegram-уведомления и что означают статусы в панели.

Шаг за шагом

Как подготовить аккаунт Selectel

Панель работает не через твой основной логин, а через отдельного сервисного пользователя с ограниченной ролью — это безопаснее.

  1. Найди Account ID

    Зайди в my.selectel.ru — в правом верхнем углу, под адресом почты, цифровой номер аккаунта. Это и есть Account ID.

  2. Создай отдельный проект под Roller IP

    В боковом меню: Облако → Проекты → Добавить проект. Дай понятное имя, например «roller-ip». После создания открой проект — Project ID будет виден в адресе страницы (UUID вида 00000000-0000-0000-0000-000000000000).

  3. Создай сервисного пользователя

    В разделе Идентификация и доступ → Пользователи добавь нового пользователя — не привязывай его к личной почте, придумай отдельный логин (например ip-roller-bot) и сложный пароль. Это username/password, которые пойдут в форму «Добавить аккаунт».

  4. Выдай роль vpc.external_access.admin — именно на уровне проекта

    В том же разделе управления доступом выбери созданного пользователя → добавить роль → область действия: твой проект из шага 2 → категория ролей vpc → роль vpc.external_access.admin.

    ⚠
    Именно admin, а не vpc.external_access.user — роль user даёт только просмотр и изменение уже существующих плавающих IP, но явно запрещает их создание и удаление (docs.selectel.ru), а панели нужны обе операции на каждом цикле. И не выдавай роль администратора аккаунта целиком — она открывает управление всем аккаунтом (биллинг, другие проекты), для панели достаточно одной роли vpc.external_access.admin на одном проекте.

  5. Добавь аккаунт в панели

    Кнопка «+ Добавить аккаунт» на дашборде → впиши название для себя, Account ID, username/password сервисного пользователя и Project ID.

  6. Выбери зоны и запусти

    На дашборде у нового аккаунта нажми «выбрать зоны», отметь нужные (Москва и/или Санкт-Петербург), сохрани — и жми «Старт».

🔒
Пароль Selectel шифруется в SQLite ключом CREDENTIALS_ENCRYPTION_KEY. Храни ключ отдельно от резервной копии базы и не теряй его: без ключа сервис не сможет войти в Selectel. Закрой права на .env и каталог data/; подробности — в файле DEPLOY.md в составе проекта.

Зоны и cooldown

Как устроено распределение по зонам и сервисные предохранители.

ru-1 · ru-3 · ru-9
Санкт-Петербург
gis-1 · gis-2
Выключены (аттестован. сегмент)
ℹ
Сервисный лимит запросов применяется ко всем workers вместе. Переключение зоны не обходит ограничение. Выбирайте зоны только для ресурсов, которыми вы вправе управлять.
✓
Скорость ограничивается общим лимитом для всех аккаунтов, а не отдельно на каждый. После 429 приложение учитывает Retry-After, если он передан, и уходит на паузу. Значения в конфигурации — защитные настройки приложения, а не подтверждённые лимиты провайдера.

Telegram-уведомления

Telegram не обязателен. Если заданы токен и chat_id, бот сообщает о совпадениях и присылает почасовую статистику роллинга в виде Rich Message с секциями и таблицами. Для кнопок панели и истории IP задайте TELEGRAM_PANEL_URL.

  1. Создай бота

    Напиши @BotFather в Telegram → /newbot → следуй инструкциям. В конце получишь токен вида 123456789:AAExampleTokenHere — это TELEGRAM_BOT_TOKEN.

  2. Узнай chat_id

    Добавь бота в нужную группу (или используй личный чат с ним), отправь любое сообщение, затем узнай ID чата — проще всего через бота @userinfobot (для группы ID будет отрицательным числом). Это TELEGRAM_CHAT_ID.

  3. Пропиши в .env на сервере

    Открой /opt/ip-roller/.env, заполни:

    TELEGRAM_BOT_TOKEN=твой_токен TELEGRAM_CHAT_ID=твой_chat_id TELEGRAM_HOURLY_REPORT_ENABLED=true TELEGRAM_REPORT_TIMEZONE=Europe/Moscow

  4. Перезапусти сервис

    systemctl restart ip-roller — без этого новые значения из .env не подхватятся.

  5. Проверь подробный отчёт вручную

    На сервере выполни cd /opt/ip-roller && sudo -u iproller .venv/bin/python -m app.telegram_reports --test. Бот отправит тестовый отчёт за последний завершённый час. Обычный отчёт отправляется автоматически через две минуты после каждого часа. Чтобы отключить его, укажи TELEGRAM_HOURLY_REPORT_ENABLED=false.

    Сводка содержит количество выделений/проверок, совпадения и повторы, 429 и другие ошибки, состояние аккаунтов и статистику по зонам. Стоимость показывается только при заданной подтверждённой ставке FLOATING_IP_COST_PER_HOUR_RUB; без неё бот явно сообщает, что оценка отключена.

Статусы аккаунта

СтатусЧто значит
runningВоркер активен, перебирает IP по выбранным зонам.
stoppedОстановлен вручную (или ещё не запускался).
cooldownПоймали лимит Selectel (429) или собственный защитный порог — ждём, ничего делать не нужно, само возобновится.
errorОшибка при обращении к API (чаще всего — неверные данные аккаунта или не назначена роль). Подробности — в поле под статусом и во вкладке «Логи».

Белый список CIDR

Список диапазонов IP, которые считаются «в БС РКН/ТСПУ» — задаётся вручную и правится на сервере, а не в веб-панели. Актуальный список по городам виден прямо на дашборде.

📄
Файл на сервере: /opt/ip-roller/config/cidr_whitelist.json. После правки — systemctl restart ip-roller, чтобы список перечитался.

Частые ошибки

СимптомПричина и что делать
401 / 403 при старте Неверные username/password/Account ID/Project ID, либо сервисному пользователю не назначена роль vpc.external_access.admin на этом проекте — перепроверь шаги в разделе «Сервисный пользователь и проект».
429 Too Many Requests Сервис учитывает заголовок Retry-After, если он есть, и ждёт. Проверяйте лимиты и расходы в кабинете провайдера.
Quota exceeded Ошибка запроса или квоты. Проверьте HTTP-код, права сервисного пользователя и состояние проекта в Selectel; неисправный запрос не повторяется циклически.
Аккаунт не стартует, зон не выбрано Перед стартом обязательно выбери хотя бы одну зону во вкладке «Зоны».
